# Cybersecurity Basics

## 1. CIA Triad

The CIA Triad is the basic security model used to protect information and systems.

### Confidentiality
Confidentiality means that information should be accessible only to authorized users.

**Examples:**
- Passwords
- Access control
- Encryption

### Integrity
Integrity means that information should remain accurate and should not be modified without authorization.

**Examples:**
- Hashing
- Digital signatures
- File integrity monitoring

### Availability
Availability means that systems and information should remain accessible when required.

**Examples:**
- Backups
- Redundant systems
- DDoS protection

---

## 2. Threat Types

### Phishing
Phishing uses fake emails, messages, or websites to trick users into revealing sensitive information.

### Malware
Malware is malicious software designed to damage systems, steal information, or gain unauthorized access.

### DDoS
Distributed Denial-of-Service (DDoS) attacks attempt to make a service unavailable by overwhelming it with traffic or requests.

### SQL Injection
SQL Injection occurs when malicious input interferes with an application's database queries.

### Brute Force
A brute-force attack repeatedly tries different passwords or credentials until a valid one is found.

### Ransomware
Ransomware is malware that blocks access to data, commonly by encrypting files, and demands payment.

---

## 3. Attack Vectors

### Social Engineering
Manipulating people into revealing sensitive information or performing unsafe actions.

### Wireless Attacks
Attacks that target wireless networks, communication, or authentication mechanisms.

### Insider Threats
Security risks caused by authorized users who intentionally or accidentally misuse their access.

---

## Conclusion

Understanding cybersecurity fundamentals helps identify threats, protect systems, and apply appropriate security controls.
