# Cybersecurity Lab Project

## Overview

This project demonstrates a practical cybersecurity laboratory covering cybersecurity fundamentals, Linux, networking, cryptography, and common security tools.

## Objectives

- Understand basic cybersecurity concepts
- Build a controlled cybersecurity lab
- Practice Linux fundamentals
- Understand networking concepts
- Perform basic cryptography operations
- Familiarize with common cybersecurity tools

## Lab Environment

- Attacker Machine: Kali Linux
- Target Machine: Metasploitable2
- Web Target: DVWA
- Virtualization: VMware
- Network: NAT + Host-only
